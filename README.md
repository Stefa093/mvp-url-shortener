# Mini URL Shortener API

A lightweight URL shortener service built with Python and FastAPI as part of a technical MVP challenge.

## Features

-   Create short URLs with a randomly generated six-character code.
-   Redirect short URLs to their original destination using HTTP 302.
-   Track click events and basic analytics.
-   Retrieve statistics for each shortened URL.
-   Validate HTTP and HTTPS URLs.
-   Return HTTP 400 for invalid URLs and HTTP 404 for unknown codes.
-   Support HEAD requests to inspect redirects without recording clicks.

## Technologies

-   Python 3.11+
-   FastAPI
-   Pydantic
-   Uvicorn
-   pytest
-   HTTPX

## Installation

Clone the repository and navigate into the project directory.

git clone [https://github.com/Stefa093/mvp-url-shortener.git](https://github.com/Stefa093/mvp-url-shortener.git)  
cd mvp-url-shortener

Create and activate a virtual environment on macOS or Linux:

python3 -m venv .venv  
source .venv/bin/activate

Install dependencies:

```
python -m pip install -r requirements.txt
```

## Running the application

Start the development server:

```
uvicorn app.main:app --reload
```

The API will be available at:

[http://127.0.0.1:8000](http://127.0.0.1:8000/)

Interactive API documentation:

[http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)

## API Examples

### Create a short URL

curl -X POST [http://127.0.0.1:8000/shorten](http://127.0.0.1:8000/shorten) \\  
  -H "Content-Type: application/json" \\  
  -d '{"url":"[https://example.com](https://example.com/)","label":"Example"}'

Example response (the code is randomly generated):

{  
  "code": "aB7xQ2",  
  "short\_url": "[http://127.0.0.1:8000/aB7xQ2](http://127.0.0.1:8000/aB7xQ2)"  
}

### Redirect to the original URL

```
curl -i 
```

Use the code generated by your own request.

To inspect response headers using HEAD:

```
curl -I 
```

### Retrieve statistics

```
curl 
```

### Test invalid URL handling

curl -i -X POST [http://127.0.0.1:8000/shorten](http://127.0.0.1:8000/shorten) \\  
  -H "Content-Type: application/json" \\  
  -d '{"url":"not-a-valid-url"}'

Expected status: HTTP 400.

## Design Notes

1.  I chose an in-memory dictionary to keep the MVP simple and focused on the three-hour time limit.
2.  Each generated code contains six random alphanumeric characters using Python's `secrets` module.
3.  The application checks for existing codes before storing a new shortened URL.
4.  Pydantic validates HTTP and HTTPS URLs, with explicit HTTP 400 error handling.
5.  Clicks are stored as individual events with timestamps and User-Agent information.
6.  A separate HEAD endpoint allows redirect inspection without increasing the click counter.
7.  In-memory storage is temporary, so all stored links and analytics are lost when the process restarts.
8.  For production, I would introduce persistent storage, concurrency-safe code uniqueness, rate limiting and improved security.
9.  With more time, I would add link expiration, QR code generation and more comprehensive automated tests.

## Limitations

This project is a demonstration MVP, not a production-ready service. It uses process-local storage and does not provide authentication, persistent analytics or advanced abuse prevention.
